Reference · 2026

The Vim Cheat Sheet — from muscle memory to mastery

A structured reference built in three escalating tiers. Start at the top, work your way down — every command is paired with a description, the mode it lives in, and a working example. Designed for both quick lookup when you forget a key and slow reading when learning the ropes.

Notation Legend

{motion}a movement (w, 3j, G, etc.)
{count}repeat a command N times
<CR>press Enter
<Esc>press Escape
<C-x>Ctrl + x
{char}a single character
{pat}a search pattern
<leader>user-defined prefix (often \)
"aregister "a" prefix
NORMALdefault mode — commands
INSERTtyping text
VISUALselection (v, V, Ctrl-v)
EXcommand-line (:commands, /search)
Part I · Beginner

Basic & Everyday Use

The 5% you'll use 95% of the time. Learn these first, repeat until your fingers forget you don't know them.

Essential Navigation
Cursor movement, scrolling, jumping to lines
~20 cmds

Cursor Movement

KeysDescriptionExample
N h j k lleft / down / up / right (one char). Whole reason Vim exists — keep fingers on home row.5j ↓ 5 lines down
N w bforward / back by word (stops at punctuation).dw → delete next word
N W Bforward / back by WORD (whitespace-delimited, ignores punctuation).3W skip 3 WORDs
N e Eend of word / WORD (one before the start of next).ge → prev word end
N 0 $start of line / end of line.d$ delete to EOL
N ^first non-blank character on the line.y^ yank to first char

Scrolling & Jumps

KeysDescriptionExample
N <C-d> <C-u>scroll down / up half a page (cursor stays put unless it falls off screen).10<C-u> scroll up 10
N <C-f> <C-b>scroll forward / back a full page.<C-f> one page down
N gg Gfirst line / last line of file.:128 ↵ or 128G
N H M Lmove cursor to top / middle / bottom of visible screen.5H top, 5L bot
%jump to matching () {} [] (very useful in code).cursor on { → jumps to }
Tip: Most movement commands take a count — 5j moves down 5 lines, 3w jumps 3 words. This composability is Vim's superpower.

Deleting

KeysDescriptionExample
N xdelete character under cursor (like Delete).4x delete 4 chars
N Xdelete character before cursor (like Backspace).—
N dddelete whole line (also yanks it into register 1).3dd delete 3 lines
N d{motion}delete everything covered by motion — the core composable delete.dw, de, d$
N Ddelete to end of line (equivalent to d$).D$ from cursor
N r{char}replace single char (no insert mode entered).rx swap char for x
N Jjoin current and next line with a single space.3J join 3 lines
N ccchange whole line (delete + insert mode).cc reset<Esc>

Undo / Redo / Repeat

KeysDescriptionExample
N uundo last change.3u undo 3 steps
N <C-r>redo (re-applies an undone change).—
N .repeat last editing command — the most under-rated key in Vim.cw + then 12.
The dot command (.) is the single biggest leverage point in Vim. Do a sensible edit once, then n. to repeat it everywhere you want it.

Searching

KeysDescriptionExample

Selecting

KeysDescriptionExample
V venter character-wise visual mode.v2w select 2 words
V Venter line-wise visual mode.V select whole line
V <C-v>enter block visual mode (column selection).see Block section
V omove cursor to the other end of selection (without re-entering mode).v2w, o, → extend back

Text Objects

Repeating & Counting

Flags & Specials

KeysDescriptionExample
EX g c i I eglobal, confirm, ignore case, Icase-preserving, e no error on miss.:%s/foo/bar/gci
EX \\< \\>match word boundaries (magic mode).:s/\\<foo\\>/bar/g
EX \\| \\( \\)alternation and capturing group (magic). Backrefs are \1 \2.:s/(foo)\\([0-9]\\)/v\\1/g

Tip: The / in :s/... is just a separator. Use :s#path/#/new# when your pattern contains slashes — easier on the eyes.

Block Visual Mode (column editing)

KeysDescriptionExample
V <C-v>enter block visual (rectangular) mode.<C-v>3j 4 columns
V I{text}<Esc>insert text at left edge of every selected row (types on all lines after <Esc>).add // comment
V A{text}<Esc>append text at right edge.add ; to each line
V $extend block to end of line — even ragged ones.column to EOL
V c Cchange block (insert uniform replacement).—
V r{char}replace each char in block with one char (no insert mode).r= make all =
V x or dcut a rectangular block (leaves a hole on shorter lines).—
Power move: To prepend // to 50 lines of code, position on the first character, <C-v>49j to make a tall column, then I // <Esc>. All 50 lines get commented in one keystroke cluster.

Abbreviations

KeysDescriptionExample
I :ab {abbr} {expansion}define an insert-mode abbreviation (expands when you type the trigger word).:ab addr 221B Baker Street

Advanced Search & Regex
Pattern matching, very magic mode, global commands
~20 cmds

Magic Modes

KeysDescriptionExample
EX \mdefault magic — . * [ do regex things; everything else needs \./foo.*bar
EX \vvery magic — every special is "as you expect" (Perl-like). Recommended./\v(foo|bar)\d+
EX \Vvery nomagic — only \ and [ are special. For literal text./\V[GET]
EX \Ma one-line override for default magic./\M^\s\+

Common Atoms (use with \v)

KeysDescriptionExample
.any character./\v.c → 'a c', 'be', etc.
* + ?0+, 1+, 0-or-1 repetitions./\vd+
{n,m}between n and m repeats (in \v; in default use \{n,m\})./\v\d{2,4}
\d \w \sdigit, word char, whitespace./\v\d+
\D \W \Snegated classes./\v\S+
[a-z] [^0-9]character class / complement./\v[a-z_]+\d*
< >word boundaries (in \v)./\v<func>
( )group + capture (in \v; default needs \( \))./\v(foo)\1
|alternation (in \v; default needs \|)./\vfoo|bar
\zs \zematch start / end markers — set cursor position without consuming./\vfoo\zsbar → cursor before bar
\=no-width positive lookahead./\v\w+\=\s

Global Commands

KeysDescriptionExample
EX :g/{pat}/{cmd}run {cmd} on every line matching {pat}.:g/TODO/d
EX :g!/{pat}/{cmd}run on lines not matching (aka :v).:g!/keep/d drop others
EX :g/{pat}/s/old/new/grestrict a substitute to lines matching the pattern.:g/^/m0 reverse lines
EX :argdo {cmd}run {cmd} on every file in the argument list.:argdo %s/foo/bar/g
EX :bufdo :windo :tabdorun on every buffer / window / tab.:bufdo e
Power pattern: :g/pattern/s/old/new/g — the global command turns a line-match into a scope for a substitute. You'll see this in real refactors constantly.

Pro workflow:
  1. Make some intentional edits — that hunk is the change.
  2. :w !git diff --no-index - <(git show HEAD:<cur-file>) — review against HEAD.
  3. :g/^$/d — drop empty lines.
  4. :w — done.

i insert · <Esc> normal · : command-line · ? in trouble

The single best way to learn Vim: don't add keybindings until the default ones hurt. Configure Vim to match Vim — not Vim to match your editor.
